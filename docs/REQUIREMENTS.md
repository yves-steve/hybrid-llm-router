# Requirements

## Hardware
- Apple Silicon MacBook Pro recommended (M1/M2/M3 with 16 GB+ RAM)
- 20 GB free disk for local model cache and project dependencies
- Setup wizard can collect CPU/GPU and RAM info interactively

## Software
- macOS 13+
- Python 3.10+
- Ollama
- Git

## Optional Cloud Accounts
- Azure OpenAI resource
- OpenAI API account
- AWS account with Bedrock access
- GCP project with Vertex AI enabled

## Network and Security
- Outbound HTTPS access to cloud APIs
- Secrets stored in environment variables or a secret manager
- Do not commit API keys to source control
